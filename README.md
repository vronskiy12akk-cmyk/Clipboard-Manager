# Clipboard Manager

Менеджер буфера обмена с сохранением истории копирования.

## Возможности
- Автоматическое сохранение всего скопированного текста
- Хранение истории в JSON-файле
- Работа в фоновом режиме

## Запуск

### Python
```bash
pip install pyperclip
python clipboard_manager.py

npm install clipboardy
node index.js

go get github.com/atotto/clipboard
go run main.go

go get github.com/atotto/clipboard
go run main.go
